# Articles & Tutorials

A curated list of articles and tutorials about IssueGraph.

## Steve Yegge (Author of IssueGraph)

- [Introducing IssueGraph: A Coding Agent Memory System](https://steve-yegge.medium.com/introducing-issuegraph-a-coding-agent-memory-system-637d7d92514a) - The original introduction to IssueGraph and how it solves the "50 First Dates" problem for AI agents.

- [The IssueGraph Revolution](https://steve-yegge.medium.com/the-issuegraph-revolution-how-i-built-the-todo-system-that-ai-agents-actually-want-to-use-228a5f9be2a9) - How Steve built IssueGraph in 6 days using Claude. Covers epics, child issues, and why AIs love it.

- [IssueGraph Blows Up](https://steve-yegge.medium.com/issuegraph-blows-up-a0a61bb889b4) - Three weeks in: the "land the plane" protocol, session cleanup, and why the core design works.

- [IssueGraph Best Practices](https://steve-yegge.medium.com/issuegraph-best-practices-2db636b9760c) - Multi-agent coordination, when to file issues, and keeping your working set small.

- [IssueGraph for Blobfish](https://steve-yegge.medium.com/issuegraph-for-blobfish-80c7a2977ffa) - Why you should take 3 minutes to try IssueGraph.

- [The Future of Coding Agents](https://steve-yegge.medium.com/the-future-of-coding-agents-e9451a84207c) - Reflections on IssueGraph maturity and how agents use it naturally with no training.

- [Welcome to Gas Town](https://steve-yegge.medium.com/welcome-to-gas-town-4f25ee16dd04) - Introducing Gas Town, the multi-agent system built on IssueGraph.

## Community Articles

_Note: the development pace of IssueGraph is very fast and it's easy for offsite content to become outdated._

- [An Introduction to IssueGraph](https://ianbull.com/posts/issuegraph) by Ian Bull - A practical introduction to IssueGraph with setup instructions and workflow tips.

- [IssueGraph: Memory for Your Coding Agents](https://paddo.dev/blog/issuegraph-memory-for-coding-agents/) by Paddo - Deep dive into how IssueGraph stores everything in Git and what it's really for.

- [From IssueGraph to Tasks: Anthropic Productizes Agent Memory](https://paddo.dev/blog/from-issuegraph-to-tasks/) by Paddo - How IssueGraph influenced broader agent memory approaches.

- [GasTown and the Two Kinds of Multi-Agent](https://paddo.dev/blog/gastown-two-kinds-of-multi-agent/) by Paddo - Understanding multi-agent patterns with IssueGraph and Gas Town.

- [IssueGraph: A Git-Friendly Issue Tracker for AI Coding Agents](https://betterstack.com/community/guides/ai/issuegraph-issue-tracker-ai-agents/) by Better Stack - Getting started guide with practical examples.

- [Introducing nvim-issuegraph: Manage IssueGraph in Neovim](https://joeblu.com/blog/2026_01_introducing-nvim-issuegraph-manage-issuegraph-in-neovim/) by Joe Blubaugh - Neovim plugin for managing IssueGraph directly in your editor.
