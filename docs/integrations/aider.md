How to use issuegraph with Aider.

[Aider](https://aider.chat/) is a human-in-the-loop AI pair programming tool: unlike autonomous agents such as [Claude Code](/integrations/claude-code), it doesn't run shell commands on its own. The issuegraph integration works with that design — the AI **suggests** `issuegraph` commands, and you confirm each one with aider's `/run` command.

## Setup

### Prerequisites

- issuegraph installed and initialized in your project (see [Installation](/getting-started/installation)); run `issuegraph init` if there's no `.beads/` directory yet
- aider installed: `pip install aider-chat` (or `pipx install aider-chat`)

### Quick Setup

```bash
issuegraph setup aider
```

This creates:

- `.aider.conf.yml` — tells aider to load the issuegraph instructions
- `.aider/BEADS.md` — workflow instructions the AI reads
- `.aider/README.md` — quick reference for humans

### Verify Setup

```bash
issuegraph setup aider --check
```

### Remove the Integration

```bash
issuegraph setup aider --remove
```

This removes `.aider.conf.yml`, `.aider/BEADS.md`, and `.aider/README.md`.

## Configuration

The generated `.aider.conf.yml` loads the issuegraph instructions into aider's read-only context:

```yaml
# IssueGraph Issue Tracking Integration for Aider
# Auto-generated by 'issuegraph setup aider'

# Load IssueGraph workflow instructions for the AI
# This file is marked read-only and cached for efficiency
read:
  - .aider/BEADS.md
```

`.aider/BEADS.md` holds the workflow rules the AI follows: track all work in issuegraph (never markdown TODOs), suggest `issuegraph ready` to find work, suggest `issuegraph create` for new issues, suggest `issuegraph dolt push` at end of session — and always *suggest* commands for you to run via `/run`. You can edit it to add project-specific instructions, but rerunning `issuegraph setup aider` regenerates it.

## Workflow

### Start Session

```bash
# Aider will have access to issues via .aider.conf.yml
aider

# Or manually inject context
issuegraph prime | aider --message-file -
```

### Inside Aider

Aider's own commands start with `/` (`/run`, `/add`, `/help`); anything else is a message to the AI. The AI suggests issuegraph commands, and you execute the ones you approve with `/run`:

```text
You: What issues are ready to work on?

Aider: Let me check the available work. Run:
/run issuegraph ready

You: Let's work on bd-42

Aider: To claim it, run:
/run issuegraph update bd-42 --claim
```

To give the AI full issuegraph context mid-session, run `/run issuegraph prime` — the AI reads the output and picks up the complete workflow guide.

### During Work

Use issuegraph commands alongside aider:

```bash
# In another terminal or after exiting aider
issuegraph create "Found bug during work" --deps discovered-from:bd-42 --json
issuegraph update bd-42 --claim
issuegraph ready

# Link an already-created issue as discovered work
issuegraph dep add bd-77 bd-42 --type discovered-from
```

### End Session

```bash
issuegraph dolt push
```

## Best Practices

1. **Keep issues visible** - Use `issuegraph prime` to inject issue context
2. **Push regularly** - Run `issuegraph dolt push` after significant changes
3. **Use discovered-from** - Track issues found during work
4. **Document context** - Include descriptions in issues
5. **Aider commits, issuegraph syncs** - Aider auto-commits your code changes; issue data moves separately with `issuegraph dolt push`

## Example Workflow

```bash
# 1. Check ready work
issuegraph ready

# 2. Start aider with issue context
aider --message "Working on bd-42: Fix auth bug"

# 3. Work in aider...

# 4. Create discovered issues
issuegraph create "Found related bug" --deps discovered-from:bd-42 --json

# 5. Complete and push
issuegraph close bd-42 --reason "Fixed"
issuegraph dolt push
```

## Troubleshooting

### Config not loading

```bash
# Check config exists
cat .aider.conf.yml

# Regenerate
issuegraph setup aider
```

Aider reads `.aider.conf.yml` at startup, so restart aider (`/exit`, then `aider`) after regenerating.

### Issues not visible

```bash
# Use issuegraph prime to inject issue context
issuegraph prime | aider --message-file -

# Or check database health
issuegraph doctor
```
