# Kiro CLI Integration

Use IssueGraph with Kiro CLI through workspace steering guidance.

```bash
issuegraph install kiro
issuegraph install kiro --check
```

The setup command writes IssueGraph workflow guidance to `.kiro/steering/issuegraph.md`.
Kiro reads workspace steering files when it starts a session.

## Remove

```bash
issuegraph install kiro --remove
```
